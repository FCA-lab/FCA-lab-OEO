# Experiment results

Classification workbooks and checkpoints are stored under `classification/`;
construction workbooks and checkpoints are stored under `construction/`.
Classification figures default to `figures/classification/`; construction figures
use `construction/figures/`. Consult each workflow's configuration for overrides.

These files are ignored by Git. Selected paper results and figure CSV/PDF/PNG
sets are intended for a separate archive, with checksums and execution provenance.
Legacy/exploratory outputs are not substitutes for the paper workbooks listed in
[the artifact map](../docs/classification/paper_artifacts.md).
