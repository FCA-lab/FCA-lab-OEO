# Historical migration provenance

`provenance.json` records the initial migration from the existing FCA-lab project,
including source paths, checksums and import adjustments. It is a historical
snapshot, not a manifest of the current checkout. Construction algorithm logic
was preserved during that migration; later changes are recorded in Git.

For the classification paper, use [the current reproduction guide](classification/reproduction.md)
and [the result/version map](classification/paper_artifacts.md). For the earlier
3WOC paper, use [the construction reproduction guide](construction/reproduction.md).
The current source tree is not a single original execution snapshot for all results.
