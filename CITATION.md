# Citing the code and papers

Please cite the paper corresponding to the functionality used. Cite both when
using both the classification and 3WOC construction methods. These are academic
citation requests, not additional conditions of the MIT license in LICENSE.

## Classification

The classification implementation provides direct OEO necessary-attribute rule
extraction and prediction. When citing the software, record its name, software
creators, version and the exact commit used. Algorithm and experiment locations
are listed in REVIEW_GUIDE.md.

## 3WOC concept construction

Zhuo Zhang, Yuhao Jin, Xincan Zhao, and Yujing Ba. 2025.
*A Fast Algorithm for Three-Way Object-Oriented Concept Acquisition*.
Applied Sciences, 15(12), 6486. https://doi.org/10.3390/app15126486

```bibtex
@article{Zhang2025ThreeWOC,
  author  = {Zhang, Zhuo and Jin, Yuhao and Zhao, Xincan and Ba, Yujing},
  title   = {A Fast Algorithm for Three-Way Object-Oriented Concept Acquisition},
  journal = {Applied Sciences},
  year    = {2025},
  volume  = {15},
  number  = {12},
  pages   = {6486},
  doi     = {10.3390/app15126486}
}
```

The title above follows the published metadata; “3WOC” is the algorithm name,
not an added prefix to the paper title. This repository includes regenerated
construction experiments, not the original publication's experimental records.
